# Recursive Directory Scanner & Interactive HTML Map Generator

# Overview
This TypeScript CLI application recursively scans a target directory on a user's file system and generates a standalone, interactive HTML visual map of the folder hierarchy. Built using TypeScript and Node.js, it asynchronously traverses directories, aggregates file metrics, and embeds the resulting nested JSON tree directly into a self-contained HTML template for instant browser exploration.
